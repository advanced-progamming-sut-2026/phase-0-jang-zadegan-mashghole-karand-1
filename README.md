## How to run the app?

Console (terminal) version:

```bash
./gradlew :core:run
```

Desktop (LibGDX graphics) version:

Run Game Client:

```bash
./gradlew :desktop:run
```

Run Game Server:

```bash
./gradlew :server:run
```
